# 4.2 Pruebas funcionales (CP-01 a CP-27)

**Objetivo:** comprobar que cada requisito funcional (RF-01 a RF-20) y sus flujos alternos se cumplen en la aplicación.

**Cómo se usa:** cada caso tiene pasos y el resultado esperado. Ejecuta los pasos en el navegador, marca el resultado y, si algo falla, registra un DEF-nn con la [plantilla de defectos](plantilla_defectos.md). Cada caso también indica el comando de sus pruebas automatizadas, cuya salida sirve como evidencia complementaria.
